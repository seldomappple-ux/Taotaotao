这次补丁用于把轻量模板里原本“有治理容器但缺少触发规则”的问题继续补齐, 重点是把 bug / 异常记录、关键操作留痕和最小多 agent 入口层正式写进模板。

## 本次处理

- 在 `lightweight-comparison-test` 中补入 bug / 异常触发记录规则与关键操作留痕规则
- 在 `lightweight-general` 中补入通用治理触发记录规则
- 把两个轻量模板都明确收口到“最小多 agent 入口层”和“多 IDE 扩展层”的区分
- 把 `GEMINI.md` 纳入最小多 agent 入口层
- 更新模板库入口说明与模板准入标准

## 持久规则

- 模板中的“自动记录”默认按“触发即记”理解, 不依赖是否已经接入自动化
- 用户提出 bug、回归、行为异常、规则冲突时, 必须落到稳定记录位置
- `render`、`validate`、结构迁移、批量改名和规则调整都属于需要留痕的治理事件
- 最小多 agent 入口层可以单独存在, 不应与 `.cursor/`、`.github/`、`.opencode/` 这类多 IDE 扩展层混为一类
