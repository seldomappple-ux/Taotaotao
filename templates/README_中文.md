# 模板库说明

这个目录用于存放可复用项目模板的正文内容。

根目录的 [`TEMPLATES.md`](../TEMPLATES.md) 只负责列出模板入口, 不承载模板正文。

## 当前模板

- [`lightweight-comparison-test/`](./lightweight-comparison-test/): 轻量对比测试模板（默认不带多 IDE 适配层）

## 使用原则

- 模板正文放在各自的子目录中维护
- 模板应沉淀“方法”和“稳定规则”, 不搬运具体项目案例
- 需要新增模板时, 先更新根目录 `TEMPLATES.md`, 再补对应子目录正文

## 模板准入标准

- 每个模板必须有独立子目录
- 每个模板必须有目录说明文件
- 每个模板必须明确适用场景
- 每个模板必须说明“迁移什么 / 不迁移什么”
- 模板列表页只做索引, 不承载正文
- 子目录名称使用稳定 slug, 避免随意改名
