# v1.3.2 主线提升总结

这份文档是 `v1.3.2` 主线提升的问题真源与版本总结。

它不重写 `v1.2.0` 的历史治理迭代结论。`v1.2.0` 仍然是增量决议与下一轮索引机制的历史落地点, `1.3.2` 是当前仓库新的正式主线版本。

## 版本定位

- 当前正式版本号: `1.3.2`
- 展示标签: `v1.3.2`
- 主线提升日期: `2026-06-02`
- 上一正式版本: `1.2.1`

本轮主线提升解决的是一个口径问题:

- 仓库已经进入模板库、轻量治理模板与最小多 agent 入口层的后续承接阶段
- 旧入口仍把 `1.2.x` 当作当前主线, 容易让接手者误判下一步仍停留在 `v1.2.0` 收口上下文
- 用户已明确要求把 `1.3.2` 提升为主线

## 本轮边界

本轮纳入主线:

- 三处版本机器真源统一升级到 `1.3.2`
- 根目录人读入口更新为 `v1.3.2`
- `UPGRADE_SUMMARY.md` 增加 `v1.3.2` 当前主线条目
- `NEXT_ITERATION_BASELINE.md` 改为承接 `v1.3.2`
- `DELTA_DECISIONS.md` 的当前迭代和仓库版本改为 `v1.3.2`
- 新增本 summary、实施 plan 和 progress entry

本轮不做:

- 不改写 `v1.2.0` 历史文档的原始结论
- 不把 `baseline refresh` 自动化补做为发布阻塞项
- 不把模板库当前未完成的后续工作伪装成已经完成的功能

## 收口结论

- `1.3.2` 是当前正式版本号
- `v1.3.2` 是当前主线展示标签
- `v1.2.0` 继续保留为已完成的历史治理迭代标签
- 后续新工作应优先从 `docs/NEXT_ITERATION_BASELINE.md` 和本文件承接
